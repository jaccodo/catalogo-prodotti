# Catalogo Prodotti

App per il telefono con il catalogo prodotti del locale: ricerca, filtri, aggiunta e modifica dei prodotti, confronto tra offerte dei fornitori.
Accesso con Google; il catalogo è condiviso tra gli account autorizzati nelle regole di Firestore.
Si installa sul telefono come app (PWA) e si apre anche senza internet.

Provarla sul PC: `node server.js` e apri http://localhost:5174

I dati non sono in questo repository: stanno in Firestore (collezione `catalogo`).
